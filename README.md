# Crypto Tracker — App de Criptomoedas

Aplicativo React Native que consome a API CoinGecko para exibir criptomoedas em tempo real, com cache e gráficos.

## Stack
- **Frontend:** React Native + TypeScript
- **Estado:** TanStack Query
- **Cache e gráficos** integrados
- **API:** CoinGecko

## Funcionalidades
- Listagem de criptomoedas com preços em tempo real
- Gráficos de histórico
- Cache offline
- Atualização automática de cotações

## Como Rodar

```
git clone https://github.com/Seven903/coingecko-app.git
cd coingecko-app
npm install
npx react-native start
```
